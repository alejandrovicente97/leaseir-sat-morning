# Leaseir SAT · Cierre de la mañana

Cuadro de mando ejecutivo del SAT de Leaseir, actualizado cada mañana con los datos de Jira (proyecto LEAS). El mensaje del día en 30 segundos, reclamaciones concretas listas para enviar, KPIs, tiempos por técnico y por fase, y detalle de los tickets atascados con enlace directo a Jira.

Fuente oficial: Jira Service Desk · cola LEAS. Contraste: dashboard SAT (I. Ortiz).
